# UI Revision Notes — HTML/CSS Edition

## Keputusan yang dipertahankan
- Nama dan identitas MAPAY BANDUNG.
- Palet hijau, ivory, mint, dan apricot.
- Tipografi editorial.
- Beranda satu layar dengan video latar.
- Navigasi: Beranda, Artikel, Destinasi, Diskusi, dan ikon Login.
- Empat halaman konten dan satu halaman form login.

## Penyesuaian implementasi
- JavaScript dan JSON dihapus.
- Katalog destinasi ditulis langsung pada HTML.
- Filter destinasi memakai radio HTML dan CSS.
- Pemilihan artikel tetap menggunakan radio HTML dan CSS.
- Kontrol suara memakai elemen `<audio controls>`.
- Form Diskusi dan Login menjadi contoh tampilan; tidak ada pengiriman data.
- Tidak ada autentikasi, penyimpanan, atau fitur dinamis.

## Alasan
Penyesuaian dibuat agar implementasi sesuai batasan tugas UTS, yang hanya mengizinkan HTML/HTML5 dan CSS/CSS3 tanpa library.
