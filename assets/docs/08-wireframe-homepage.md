# Wireframe & Page Structure

Dokumen ini menjelaskan susunan lima halaman pada MAPAY BANDUNG.

## 1. Beranda
- Header transparan di atas video.
- Logo kiri, menu tengah, ikon login kanan.
- Headline dan deskripsi pada area kiri.
- Tombol Mulai Jelajah dan Tukar Cerita.
- Meta wilayah pada bagian bawah kiri.
- Pemutar ambience opsional di bawah kanan.

## 2. Artikel
- Header navigasi.
- Intro editorial.
- Kolom kiri: satu artikel penuh.
- Kolom kanan: pilihan tiga artikel.
- Radio HTML mengontrol artikel yang tampil.

## 3. Destinasi
- Heading "Mau mapay ke mana?".
- Filter kategori berbentuk pill.
- Grid empat kartu foto.
- Setiap kartu membuka ringkasan dengan `<details>`.
- Catatan dan tautan menuju Diskusi.

## 4. Diskusi
- Heading dan deskripsi komunitas.
- Kolom kiri: form contoh.
- Kolom kanan: daftar posting contoh.
- Form tidak mengirim data karena tidak ada backend atau JavaScript.

## 5. Login
- Kolom kiri: visual dan pesan selamat datang.
- Kolom kanan: form email dan kata sandi.
- Validasi dasar dari HTML; autentikasi tidak tersedia.

Susunan ini merupakan wireframe tekstual yang menjadi acuan implementasi HTML dan CSS.
