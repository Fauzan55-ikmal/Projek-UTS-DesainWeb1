## 📂 Struktur Direktori Proyek

Struktur folder dirancang modular dan siap dikembangkan untuk tugas-tugas berikutnya:

```text
MAYS-Store/
│
├── .gitignore              # Konfigurasi file/folder yang diabaikan Git
├── README.md               # Dokumentasi proyek (file ini)
│
├── index.html              # Halaman Utama 
│
├── src/                    # Folder Source Code
│   ├── css/                # Kumpulan stylesheet per halaman
│   │   ├── style.css       # Stylesheet utama
│   └── js/                 # Script interaksi halaman
│       └── script.js       # JavaScript utama
│
└── assets/                 # Folder Aset Media
    ├── audio/              # File audio latar belakang (1.mp3)
    ├── docs/               # File Dokumen Requirement (.docx)
    ├── img/                # Kumpulan gambar produk dan banner
    └── video/              # File video kampanye visual (1.mp4)
```
